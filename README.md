# Data Cleaning & Customer Automation System

A professional Python automation script designed to help businesses extract, clean, and standardize large customer databases.

## Features
- **Auto File Picker:** Opens a real Windows GUI window to let users easily select data files.
- **Advanced Text Cleaning:** Automatically removes accidental spaces and fixes inconsistent capitalization (lower casing).
- **Line Break Fixer:** Splits combined or raw text blocks into 50 individual, organized customer rows automatically.
- **Smart Counter:** Numbers and structures final reports cleanly with formatting lines (`---`).

## Built With
- **Python 3**
- **Tkinter** (For the Graphical File Dialog)
- **OS & String Modules**

## How To Run
1. Download `process_50.py` and your raw text database.
2. Run the script inside VS Code.
3. Select your raw text file from the popup window.
4. Enjoy your perfectly cleaned `cleaned_50_report.txt` file!
